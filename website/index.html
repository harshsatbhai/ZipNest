Features

Everything you need. Nothing that phones home.

100% offline

Works on a plane, in a bunker, or on an air-gapped machine. No sign-in, no cloud, no telemetry, ever.

Built for codebases

Honours .gitignore and skips node_modules, .git, __pycache__, .venv and other junk, so you share source, not gigabytes.

Password protection

Encrypt archives with AES-256, the strongest standard ZIP supports, compatible with 7-Zip, WinRAR and more.

Safe extraction

Every archive is checked first. Path-traversal tricks, sneaky symlinks and zip bombs are blocked before anything touches your disk.

Fast & streaming

A Rust engine streams data in chunks, so multi-gigabyte folders don't eat your RAM. Already-compressed media is stored, not re-squeezed.

Never overwrites

Extracts into a fresh folder by default, writes ZIPs atomically, and cleans up if you cancel. Your existing files stay untouched.

Install & uninstall

Up and running in a minute

Install

  1. Download ZipNest-windows-x64-setup.exe.
  2. Double-click it and follow the installer. No administrator rights required.
  3. If Windows SmartScreen shows “Windows protected your PC”, click More info → Run anyway. This appears for new apps that aren't code-signed yet.
  4. Launch ZipNest from the Start menu.

Uninstall

  1. Open Settings → Apps → Installed apps.
  2. Find ZipNest, click ⋯ → Uninstall.

The uninstaller removes the app, its shortcuts and its registry entries. Your ZIP files are never touched.

Install

  1. Download ZipNest-macos-universal.dmg and open it.
  2. Drag ZipNest into the Applications folder.
  3. First launch: if macOS says the developer can't be verified, right-click ZipNest → Open → Open. On macOS 15+, use System Settings → Privacy & Security → Open Anyway.

Uninstall

  1. Quit ZipNest.
  2. Drag ZipNest from Applications to the Trash.

Optional full clean-up (window size cache only):

rm -rf ~/Library/WebKit/app.zipnest.desktop ~/Library/Caches/app.zipnest.desktop

Install (.deb)

sudo apt install ./ZipNest-linux-amd64.deb

ZipNest then appears in your app menu and in “Open with” for .zip files.

AppImage (any distro)

chmod +x ZipNest-linux-x86_64.AppImage && ./ZipNest-linux-x86_64.AppImage

Uninstall

sudo apt remove zip-nest

For the AppImage, just delete the file.

Security & privacy

Your files never leave your computer

No network access

The app contains no networking code and its sandbox permissions don't allow any. Compression and extraction happen entirely on your machine.

Locked-down by design

Built on Tauri with a strict content-security policy and minimal permissions: the interface can only ask the Rust core to zip, unzip or open a file picker.

Defends against bad archives

Blocks “zip-slip” path traversal, refuses to create symlinks, sanitises file names, and stops zip bombs that claim to expand to absurd sizes.

Open & reproducible

All source code is public. Installers are built by GitHub Actions straight from tagged source, with published SHA-256 checksums.

Verify your download

Compare the output with the matching line in SHA256SUMS.txt.

Windows (PowerShell)
Get-FileHash .\ZipNest-windows-x64-setup.exe
macOS
shasum -a 256 ZipNest-macos-universal.dmg
Linux
sha256sum ZipNest-linux-amd64.deb

FAQ

Questions, answered

Is ZipNest really free?

Yes. ZipNest is free and open source under the MIT license. There are no ads, trials or paid tiers.

Does it need the internet?

Only to download the installer from this page. After that ZipNest works completely offline. (On a very old Windows 10 PC without Microsoft Edge WebView2, the installer fetches that system component once. Windows 11 already includes it.)

Which archive formats are supported?

ZipNest creates standard .zip files that open everywhere. It extracts .zip archives using Deflate, BZip2, LZMA and Zstandard compression, including AES- and ZipCrypto-encrypted archives.

How big can files be?

There's no practical limit. ZipNest uses Zip64 for files over 4 GB and streams data, so it doesn't need to load files into memory.

What exactly gets skipped when I zip a project?

With the default settings: anything matched by your .gitignore, plus .git, node_modules, __pycache__, .venv, .next, .DS_Store and similar folders. You can turn each filter off before zipping.

Why does my computer warn me when installing?

Windows and macOS show a warning for apps that aren't signed with a paid developer certificate. ZipNest is safe to run, and you can confirm your download is genuine with the SHA-256 checksums above.

I forgot the password to my archive. Can you recover it?

No. AES-256 encryption is designed so that nobody, including us, can open the archive without the password. Keep it in a password manager.
